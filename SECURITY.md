# Security / Seguridad

**EN** — If you find a security problem, please do **not** open a public issue. Use GitHub's
“Report a vulnerability” button (Security tab of this repository) so it can be fixed before it is disclosed.
PVEMon is provided as is, without guaranteed support; reports are handled when possible.

**ES** — Si encuentras un fallo de seguridad, **no abras un Issue público**: usa el botón «Report a vulnerability»
(pestaña Security de este repositorio) para poder corregirlo antes de darlo a conocer.
PVEMon se ofrece tal cual, sin soporte garantizado; los avisos se atienden cuando es posible.
